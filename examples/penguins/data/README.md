# The data: Palmer Penguins

`penguins.csv` is the file of that name from the palmerpenguins R package,
version 0.1.1, as published on CRAN on 2022-08-15
(`palmerpenguins_0.1.1.tar.gz`, file `inst/extdata/penguins.csv`): 344
records of 8 columns (species, island, bill length and depth, flipper length,
body mass, sex and year).
